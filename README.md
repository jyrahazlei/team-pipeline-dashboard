# Team Pipeline Dashboard

A dashboard for tracking a small team's pipeline (leads → contacted →
applied → approved → realized), team-level KPIs, and individual member
performance.

Built as a portfolio project to demonstrate business, analytics, and
product thinking through a small, working tool — not as a showcase of
advanced engineering.

## Data & privacy

All data in this repository is **synthetic and anonymized**. Members are
labeled things like "Member 01" and pipeline entries like "EP 01" — there
are no real names, phone numbers, emails, IDs, or other identifying
information anywhere in this repo, and none ever will be. Any real data
used privately by the project owner is kept entirely outside this repo
(see `.gitignore`).

## Tech stack

- React + Vite (JavaScript)
- Plain CSS
- LocalStorage / local data files for now — no backend, auth, database,
  or external API integrations unless a real need for one comes up later

## Running locally

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.
